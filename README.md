# Xenia

Xenia is a control plane for coordinating coding agents across machines and projects. It combines a mobile-friendly web app with a controller and lightweight services on worker nodes.

**Status: early prototype.** This is not yet the first release described in the [product brief](docs/product-brief.md). See the [architecture plan](docs/architecture.md) for the intended design and the [installation and usage guide](docs/installation.md) for current behavior. See the [desktop worker guide](docs/desktop-workers.md) for the macOS and Windows apps and the [resource-use baseline](docs/performance.md) for initial measurements.
